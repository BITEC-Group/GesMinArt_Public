GesMinArt — accès par appareil

Plateforme nationale de gestion des activités minières artisanales. Choisissez la version de votre appareil.

Les applications se connectent au serveur GesMinArt : indiquez son adresse sur l'écran de connexion (rubrique « Serveur »). Compte de démonstration : identifiant admin. Les binaires de test ne sont pas signés : Windows et macOS peuvent afficher un avertissement de sécurité. Liens publics : aucun compte GitHub n'est nécessaire. iPhone / iPad : build pour simulateur uniquement (installation sur appareil réel : TestFlight, non fourni).
