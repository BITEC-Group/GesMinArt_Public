# GesMinArt - Telechargements

Binaires de test de la plateforme GesMinArt (gestion des activites minieres artisanales, RDC). Ce depot ne contient **aucun code source**.

Voir la section **Releases** : un fichier par appareil (Android, Windows, macOS, Linux, web).

- Binaires non signes : Windows et macOS peuvent afficher un avertissement de securite.
- Donnees de demonstration, montants illustratifs.
- Les applications se connectent a un serveur GesMinArt : indiquer son adresse sur l ecran de connexion.
